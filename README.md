One funny line: the excuse a robot vacuum gives after eating a sock,
reported as a completed system event — job ID, detection time, suction
reading, intake percentage, closed status. Run `python3 main.py` to
write the entry to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR`).
